                Sistema de Análisis de Crecimiento Microbiológico
Proyecto Integrador - Programación II
    Aplicación desarrollada en Python para registrar y analizar cultivos microbiológicos obtenidos en prácticas de laboratorio

Asignatura
    Microbiología
OBJETIVO
    Facilitar el registro y análisis de cultivos microbiológicos mediante una aplicación de consola orientada a objetos.

Autor
    Dulce María Madrigal Blas

FUNCIONALIDADES 
    Registrar cultivos.
    Calcular UFC/mL.
    Clasificar crecimiento.
    Buscar cultivos
    Mostrar todos los registros.
    Generar estadísticas generales

# Clases
    Cultivo
    Representa un cultivo microbiológico.

# GestorCultivos
    Administra los cultivos registrados.

# Requisitos
    - Python 

# Ejecución

```bash
python main.py
```

# Ejemplo
    entradas:
    Colonias = 150
    Dilución = 0.001
    Volumen = 0.1
    Resultado:
    UFC/mL = 1,500,000
    Clasificación = Aceptable
