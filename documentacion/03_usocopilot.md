# Uso de GitHub Copilot

## 1. ¿Cómo utilizaste las especificaciones para solicitar código a Copilot?

Las especificaciones fueron utilizadas como guía para solicitar la implementación de cada clase.

---

## 2. ¿Qué revisaste o modificaste del código generado?

Se revisaron los constructores, atributos, métodos, validaciones y cálculos matemáticos. También se ajustaron mensajes del menú y validaciones de entrada.

---

## 3. ¿Copilot generó una respuesta incorrecta o distinta de lo solicitado?

Sí. Inicialmente propuso algunas validaciones incompletas para las entradas numéricas. Se corrigieron para evitar valores negativos y datos inválidos.

---

## 4. ¿Cómo comprobaste el funcionamiento de clases y métodos?

Se realizaron pruebas utilizando diferentes datos de entrada y comparando los resultados obtenidos contra los resultados esperados.

---

## 5. ¿Qué ventajas y limitaciones observaste?

### Ventajas

- Acelera la programación.
- Sugiere estructuras de código.
- Reduce tiempo de escritura.

### Limitaciones

- Puede interpretar mal algunos datos
- Requiere supervisión constante.
- No reemplaza el análisis del programador.

---

## 6. ¿Por qué es necesario comprender código producido con ayuda de IA?

Porque el desarrollador es responsable del funcionamiento de la aplicación y de comprender el código, también permite detectar errores, validar cálculos, realizar modificaciones y explicar la solución.
